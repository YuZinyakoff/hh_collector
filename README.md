# HH Collector: архив вакансий hh.ru

HH Collector регулярно собирает объявления о вакансиях через API hh.ru и
сохраняет историю наблюдений. Цель проекта: создать базу для исследований
спроса работодателей на профессии и навыки, его динамики и региональных различий.

Система сохраняет исходные ответы API, даты наблюдений и версии карточек.
Подробные карточки содержат тексты объявлений, а также сведения о навыках,
опыте и оплате, если работодатель их указал.

## Объём данных

На **20 ноября 2026 года** регулярный сбор охватил **4 983 910 уникальных
объявлений**. Каждое из них наблюдалось хотя бы раз с 1 июля 2026 года.
С учётом нерегулярных тестовых запусков в мае и июне общий объём архива
составляет **5 888 403 уникальных объявления**.

Каждый идентификатор hh.ru учитывается один раз, даже если объявление
встречалось в нескольких сборах. Дата начала периода относится к наблюдению,
а не к публикации. Эти числа описывают объём собранного массива, а не число
рабочих мест или полный охват рынка труда. В репозитории доступны код и
документация, сам массив данных не опубликован здесь.
